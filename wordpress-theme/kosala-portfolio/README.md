# Kosala Portfolio WordPress Theme

An installable WordPress edition of the complete portfolio website.

## Included

- Editorial responsive portfolio design
- Home, About, Highlights, Skills, Projects, Experience, Education, Certifications and Contact sections
- Moving technology marquee
- Project filtering and detail modal
- Video backgrounds and portrait media
- Mini games and interactive effects
- CV and certificate downloads
- Contact form and social/contact shortcuts
- Local portfolio assistant powered by a WordPress REST endpoint
- Native WordPress visitor counter
- Light and dark themes
- All original images, videos, CSS and JavaScript

## Install

1. In WordPress, open **Appearance > Themes > Add New > Upload Theme**.
2. Upload `kosala-portfolio.zip`.
3. Activate **Kosala Portfolio**.
4. Open **Appearance > Customize > Portfolio Identity** to change the name, role, email, phone, LinkedIn and GitHub details.
5. Set the site homepage to a static page if your WordPress configuration does not automatically use `front-page.php`.

## Notes

- The contact form uses FormSubmit and sends to the configured email shown in the generated page.
- The bundled assistant answers portfolio questions locally through WordPress. Replicate image generation requires a separate Replicate API integration and intentionally returns a configuration message until one is added.
- For upload-restricted hosting, raise the WordPress upload limit above 20 MB because the theme contains video and portfolio media.

## Requirements

- WordPress 6.0 or newer
- PHP 8.0 or newer
